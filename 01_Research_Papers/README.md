# 01_Research_Papers

## Purpose

This folder lists the academic sources reviewed for this research, organised by the same four themes used in Chapter 2 of the proposal. Full-text copies of journal and conference papers are not redistributed here because of publisher copyright; each entry instead gives the citation and a direct link (DOI or publisher URL) so the lecturer can verify the source. This mirrors how the literature review in the proposal report cites these works.

## How this maps to the proposal

Chapter 2 (Literature Review) of the Research Proposal is built directly from the papers listed below. Table 2.1 in the proposal summarises the entries marked with an asterisk (*).
